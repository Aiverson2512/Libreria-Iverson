Este es un proyecto que tenia el cuatri pasado que es una Libreria Online construida en php con mysql, panel admin, y lo que corresponde en esta asignacion que son las pruebas automatizadas con selenium


Las tecnologias que se usaron:
PHP
MYSQL
Bootstrap
HTML + CSS
Docker 
Python + Selenium + pytest


Para levantar el proyecto pues, con powershell docker compose up -d --build
Para ver el catalogo http://localhost/ . Ya desde ahi se puede ir accediendo a las demas cosas como por ejemplo el panel del administrador http://localhost/admin/index.php.

La base de datos entra en automatico con: libreria.sql, contacto.sql, usuarios.sql.

Tiene su cuenta de prueba para iniciar una automatizacion, selenium la escribe automaticamente para iniciar sesion y ejecutar las pruebas. Se debe tner Google Chrome y un python digamos que actualizado.

El reporte se crea en su carpeta aparte dentro del folder principal llamada 'reports'

Las pruebas cubren todas las historias de usuario.--
